Connect to Quercus

Sync accessible courses, assignments, announcements and Module pages directly from this device. Other devices can receive updates through your optional signed-in cloud workspace.

Find or generate your personal token in Quercus → Account → Settings → Approved Integrations. Never share it in chat or upload it as a file.

For live sync, your token travels over HTTPS through this application's private-request relay on Vercel to q.utoronto.ca. It is not retained on Vercel. If remembered, it is stored in this device's browser storage, not encrypted with an additional password.
Google Drive & file organizer

Map your existing semester and course folders, review every proposed destination, and explicitly approve new uploads. AI and automatic file movements are not used.

One-time Google Cloud OAuth setup

Create a Google Cloud project, enable Google Drive API, and configure an OAuth consent screen with yourself as a test user. Create an OAuth Client ID for a Web application, with https://quercus-pocket.vercel.app as an authorized JavaScript origin. Paste that public client ID below. No client secret is used or needed. Google may require an app-verification step for wider distribution.

The app requests two scopes: drive.metadata.readonly to inspect your existing folder structure and drive.file to create new files. Google may require you to grant specific existing folders to the app using Picker; a 403 on upload will be reported rather than requesting unrestricted write access.
