Connect to Quercus

Sync accessible courses, assignments, announcements and Module pages directly from this device. Other devices can receive updates through your optional signed-in cloud workspace.

Find or generate your personal token in Quercus → Account → Settings → Approved Integrations. Never share it in chat or upload it as a file.

For live sync, your token travels over HTTPS through this application's private-request relay on Vercel to q.utoronto.ca. It is not retained on Vercel. If remembered, it is stored in this device's browser storage, not encrypted with an additional password.
Export Quercus data

Create an export from the latest data saved on this device. Exports are generated locally. On iPhone use Share to save to Files; on desktop use Download.

The ZIP includes JSON, Markdown, CSV tables and ICS. Linked PDFs and attachments are not bundled automatically; download those from their page links.
Import Quercus export

Import a Complete JSON export for the full experience, or a ChatGPT .md export for searchable text.

On iPhone: first open this site in Safari, tap Share → Add to Home Screen, and launch the installed icon before importing. Saved exports stay on this device and are not uploaded.
